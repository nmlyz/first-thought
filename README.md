One word, the first that comes to mind. See the bounty: https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8

This program writes a single word to `entry.txt`: **defenestration** — the act
of throwing someone out of a window. No topic, no explanation, no second
draft; just the first word that arrived.

## Run

```sh
python3 main.py
```

The program writes the word to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). It uses only the
Python standard library, needs no network, and writes the same bytes on
every run.

## The word

*defenestration* — surprising, because there is a dedicated word for that;
vivid, because the image arrives whole in a single glance; and witty, because
a formal Latinate word describes a thoroughly undignified act. It beats safe
filler on every count the brief weighs: surprise first, then vividness, then
wit — and it feels chosen, not generic.
